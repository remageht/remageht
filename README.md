# Hi, I'm Emir 👋

**19 y.o. DevOps / Full-stack · Local-first & Privacy-focused · Linux**

I build private, offline-first tools that run on your hardware — no cloud, no subscriptions, no data leaks. From Go binaries and FastAPI backends to React PWA frontends, Tauri desktops and Flutter mobile apps.

`Python FastAPI` · `React 18 + TS + Tailwind` · `Tauri 2 / Rust` · `Qwen3-TTS / Fish Speech 1.5` · `SQLite` · `ffmpeg` · `CUDA`

**[remageht/personal-devops-platform](https://github.com/remageht/personal-devops-platform)** — secure platform for monitoring, Docker management and local infra automation.
`Python 3.12 / FastAPI` · `JWT` · `Docker Compose (non-root, read-only)` · `Prometheus / Grafana / cAdvisor` · `CI: Ruff / Pytest / Hadolint / Gitleaks / Trivy`

**[remageht/namaz-vakit](https://github.com/remageht/namaz-vakit)** — Prayer times, Qibla & learning (PWA). Prayer schedule, countdown, Qibla compass with gyro, sound/visual notifications, ablution + 5 prayers lessons. Offline-ready.
`PWA` · `Service Worker` · `Aladhan API` · `Geolocation` · `HTML / JS`

**[remageht/Teleport](https://github.com/remageht/Teleport)** — cross-platform app (Android / iOS / Windows / Linux / macOS) for sales reps of electronic components. Mobile-S analog: pre-selling and van-selling, offline-first SQLite + 1C sync, Bluetooth ESC/POS printing.
